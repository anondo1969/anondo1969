# Hi, I'm Mahbub

I build **open, self-hosted AI tools for life science**, including LLM infrastructure, agent workflows, and research tools designed to be useful, auditable, and privacy-conscious.

### What I'm working on

- [**openllm-setup**](https://github.com/ScilifelabDataCentre/openllm-setup): self-hosted open LLM infrastructure for Swedish research
- [**serve-template-gradio**](https://github.com/ScilifelabDataCentre/serve-template-gradio): programmatic access, MCP, and agent workflows for [SciLifeLab Serve](https://serve.scilifelab.se/) apps
- [**AI Agent & MCP workshop**](https://github.com/ScilifelabDataCentre/scilifelab-ai-agent-mcp-workshop-2026-06-09): hands-on materials for life science
- [**pause**](https://github.com/anondo1969/pause): a citation-grounded self-check on how AI may shape our habits of thought · [live](https://anondo1969.github.io/pause/) · [paper](https://doi.org/10.2139/ssrn.7270039)
- [**citation-constellation**](https://github.com/citation-cosmograph/citation-constellation): auditable citation-network analysis for researchers · [live](https://citation-constellation.serve.scilifelab.se) · [paper](https://arxiv.org/abs/2603.24216)
